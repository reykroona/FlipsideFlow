# FlipsideFlow app icon

`FlipsideFlow.png` is the master raster. `FlipsideFlow.icns` and
`FlipsideFlow.ico` package it at standard desktop icon sizes. The app spec uses
these FF assets; the original VinylFlow icons are retained for provenance.

Created with the built-in image-generation tool by editing the original icon.
Final prompt: preserve the existing thin geometric FF lettering, scale, alignment
and spacing; make the left F white (#FFFFFF), the right F orange (#F39C12), on
a square black background, with no added text or graphics.
